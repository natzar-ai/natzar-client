    Reason × failure → action (§4.2 broker table, §4.11, D12):

    • initial, reconnect, rescope: the §4.2 table: signed_out → the signed-out state; 429, 5xx, network → retry; anything else → error.
    • renew: signed_out → signed-out state; forbidden (the session is dead, revoked or refused) → ONE reconnect mint (an idle-locked frame instead stays locked, see askFailureAction); a policy refusal (origin, deployment, embedding, surface) → expired {revoked}; transient → retry (renewal is allowed after access expiry until the absolute limit).
    • fresh (the current session still works and is never ended here): signed_out → the "sign in again on " state (not an end); transient → retry, and once the bounded retries are spent, error (the join attempt failed; a manual Try again); anything else → error. Join anyway is never an ask outcome: only the server's join refusal (joinAnywayAllowed, preJoinDecision) allows it (RG4B N4).
    • successor (a call is live): every failure → keep_call.
