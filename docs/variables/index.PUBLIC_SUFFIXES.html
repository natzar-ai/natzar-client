    PUBLIC_SUFFIXES: ReadonlySet<string> = ...

    PUBLIC SUFFIXES — the FLOOR: a conservative subset of the Public Suffix List (https://publicsuffix.org/list/), embedded because this contract ships without dependencies. It can only refuse more: the authoritative decision is the injected full list (createPublicSuffixList), and without that list every wildcard is refused (public_suffix_unverified). A wildcard https://*.<base> is refused when <base> IS one of these: every name below it belongs to a different customer. <base> UNDER one (https://*.acme.vercel.app) is a registrable domain, as with the real list.

    The subset covers (1) multi-label country suffixes in common use and (2) the shared-hosting platforms partners actually deploy on. Single-label suffixes (com, app, uk, …) need no entry: a base with fewer than two labels is always refused. CCTLD_SECOND_LEVEL_LABELS additionally refuses any <generic label>.<2-letter ccTLD> base, which catches country suffixes missing here.
