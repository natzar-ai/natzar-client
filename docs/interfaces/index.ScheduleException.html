    Interface ScheduleException

    A dated change to the weekly pattern — time off, or extra hours.

    date is a local calendar date; endDate (inclusive) makes it a range — "away 2026-12-20 → 2027-01-04" is ONE exception. Both minute fields absent = the whole of each day; present = that window on each day of the range.
