    Interface PartnerEventResource

    A stored webhook event, as returned by GET /v1/events — the durable replay log behind webhook delivery. Every event is written here BEFORE any delivery attempt, so polling this endpoint is a complete, ordered substitute for (or reconciliation against) receiving webhooks.

    type/data carry exactly the discriminated payloads documented in ./webhooks (WebhookEvent); data is typed unknown here to keep this module dependency-free — narrow it via the type field using the webhook union.
