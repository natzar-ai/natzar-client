    Interface CustomerEndpoints

    The customer endpoint's routes as the browser sees them (§3.7, §4.7). The contract a non-SDK server implements: POST + JSON ≤ 4 KB + X-Natzar-Request: 1 + exact same origin, and every answer carries ENDPOINT_RESPONSE_HEADERS.
