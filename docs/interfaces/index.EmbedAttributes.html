    Optionalaccent

    accent?: string

    Accent color — the patient's own message bubbles, primary buttons and focus rings. Hex only (#0f7b6c, #fff, 3/4/6/8 digits); anything else is ignored and the default is kept.

    The widget runs in a cross-origin iframe, so your page's CSS cannot reach inside it. These attributes are the supported way to make it look like your product. They are a deliberately small, strictly validated set rather than arbitrary CSS: the frame renders health information, and a free-form style channel into it is a channel worth not having.

    Defaults to your tenant's brand color when one is configured, else the theme's own accent.

    Optionalfont-family

    "font-family"?: string

    Font family for the widget's text, e.g. Inter, system-ui, sans-serif. Letters, digits, spaces, commas, quotes and hyphens only — enough to name a stack, not enough to smuggle another declaration. The font must already be available to the browser; the widget loads no external fonts.
