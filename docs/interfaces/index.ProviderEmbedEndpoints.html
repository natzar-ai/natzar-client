    Interface ProviderEmbedEndpoints

    The provider REST route table. Keys are 'METHOD /v1/provider-embed/…'; auth: 'server' routes take your current API key and are called from your server only, auth: 'browser' routes take the pe1 session credential. For GET routes query is the query-string shape.
