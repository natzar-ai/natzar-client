    Interface PatientResource

    A patient you provisioned via POST /v1/patients.

    Partner-provisioned patients have messageChannel: 'partner': the platform never contacts them over WhatsApp/SMS — every outbound message is persisted to the consult transcript and surfaced to you via webhooks (async_consult.message) and the embed widgets.
