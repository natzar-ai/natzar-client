    Interface Endpoints

    The machine-readable route table: every Partner API route mapped to its request and response types.

    Keys are METHOD /v1/path with {id} marking the path parameter (always our id of the addressed resource). For GET routes, request is the QUERY shape; for body-carrying methods it is the JSON body. undefined means the route takes no query/body.

    Useful for building typed clients:

    Example

    type Route = keyof Endpoints;
    async function call<R extends Route>(
      route: R,
      args: {params?: Record<string, string>; request: Endpoints[R]['request']},
    ): Promise<Endpoints[R]['response']> { …fetch with Authorization: Bearer pp_…  }
