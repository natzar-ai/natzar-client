    Interface SessionsEndpoints

    The Natzar session routes (§4.5). All are auth: 'server': your key, from your server only. A request carrying Origin, Sec-Fetch-Site or Sec-Fetch-Dest is refused (Node's own sec-fetch-mode: cors is accepted); responses carry Cache-Control: no-store. POST /v1/sessions answers 201 for a mint and 200 for a renewal.
